# Bewerbung als PDF

Bewerbungsbrief am Handy ausfüllen, unterschreiben und als PDF senden. Alles bleibt auf dem Gerät, nichts wird ins Internet geschickt.

## iPhone / iPad (Web-App)

1. In **Safari** öffnen: https://erwachsenenbildungdidaktik-blip.github.io/bewerbung-pdf/
2. Teilen-Symbol → **Zum Home-Bildschirm**
3. Danach läuft die App wie eine normale App, auch offline.

## Android

APK herunterladen und installieren: [download/Bewerbung-PDF.apk](https://erwachsenenbildungdidaktik-blip.github.io/bewerbung-pdf/download/Bewerbung-PDF.apk)
(Installation aus unbekannten Quellen erlauben.)
